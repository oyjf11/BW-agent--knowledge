# 知识点清单模板

## 输出格式

提取源文档知识点后，以以下表格格式输出：

```
| 编号 | 来源章节 | 知识点摘要 | 目标分支 | 映射状态 | 处理说明 |
|------|---------|-----------|---------|---------|---------|
| KP-1 | §1 多Agent协作 | 应用开发智能体 11 个 Agent 角色 | 22-多Agent | 空白填补 | 写入 22.2 |
| KP-2 | §1 协作方式 | 任务依赖图+状态机编排 | 22-多Agent | 空白填补 | 写入 22.3 |
| KP-3 | §2.1 通用表 | 10 个通用运行表 | 41-工程底座 | 空白填补 | 写入 41.3 |
```

## 映射状态定义

| 状态 | 含义 | 后续动作 |
|------|------|---------|
| 已覆盖 | vault 已有该知识，内容充分 | 不写入（可补充此前遗漏的细节，追加而非覆盖） |
| 空白填补 | vault 对应文件存在但为空（`待补充`） | 写入完整内容，填充空模板 |
| 新增 | vault 中完全不存在对应文件或分支 | 新建 .md 文件 + 更新 `_index.md` |
| 潜在冲突 | 源文档声明与 vault 已有事实有差异 | → 进入阶段三冲突检测 |
