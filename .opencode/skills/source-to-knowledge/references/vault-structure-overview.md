## 分支名中的 ✅ 含义

- 带 ✅ 的分支：有实质内容，非空白模板
- 不带 ✅ 的分支：仅有 `_index.md` 或空白占位文件

## 文件命名规范

- 目录：`NN-主题名/` 或 `NN-主题名✅/`
- 子文件：`NN.M 子主题.md` 或 `NN.M 子主题✅.md`
- 索引文件：`_index.md`（每个目录一个，列出所有子节点为 Obsidian wiki-link）

## 笔记模板

### 概念笔记（type: concept）

**frontmatter：**
```yaml
type: concept
status: done
tags:
  - AI-Agent面试
  - <主题标签>
```

**标准节结构：**
1. 一句话定义
2. 解决什么问题
3. 如何实现
4. 项目映射
5. 高频追问
6. 我的回答要点
