# source-to-resume-bullets

## Goal
Create resume-safe bullet points grounded in source code and known project facts.

## Rules
- Do not invent metrics.
- Do not claim ownership unless supported.
- Separate:
  - 可直接写入简历
  - 需要补证据后再写
  - 不建议写
- Every strong bullet should include source evidence.
