# 5.2 Agent架构模式

> 所属分支：[[05-Agent系统化落地层/_index|05-Agent系统化落地层]]

## 子节点 / 待填充要点
- 单 Agent：实现简单、适合小任务、复杂任务容易失控、可观测性较弱
- Multi-Agent：Router Agent、Planner Agent、Executor Agent、Critic Agent、QA Agent、Report Agent
- Workflow + Agent：固定主流程、局部节点由 Agent 决策、可控性较强、企业生产更常见
- Agentic Workflow：动态规划、动态工具选择、动态反思修正、灵活性强、治理难度高
