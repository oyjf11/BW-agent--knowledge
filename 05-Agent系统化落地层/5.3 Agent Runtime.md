> 所属分支：[[05-Agent系统化落地层/_index|05-Agent系统化落地层]]

## 子节点 / 待填充要点
- State Machine：task_id、current_node、status、next_node、state_json、retry_count
- Checkpoint：状态快照、断点续跑、失败恢复、审批暂停、服务重启恢复、节点级恢复、durable execution 基础
- Event Log：过程追踪、工具调用记录、节点输入输出、错误记录、审批记录、执行记录、审计与回放
- Retry / Timeout：LLM 超时、工具超时、节点重试、最大重试次数、指数退避、失败降级
- Queue / Scheduler：异步执行、并发控制、任务排队、优先级调度、Worker 执行、任务恢复
- Cancellation：用户取消、超时取消、风险取消、人工终止、取消后状态保存
- Observability：任务状态、节点耗时、工具耗时、Token 消耗、错误率、成本、Trace 链路
