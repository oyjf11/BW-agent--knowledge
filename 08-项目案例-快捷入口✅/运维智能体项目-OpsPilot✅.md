# 运维智能体项目-OpsPilot

## 30 秒版本
AI 运维智能体，从工单/告警接入到根因分析全链路：分诊 → 多源证据采集 → 根因假设 → 处置建议 → 人工审批 → 执行验证 → RCA 复盘。核心设计原则：只读证据优先，写操作需人工审批。

## 1 分钟版本
运维智能体偏诊断和决策任务，重点是证据链、安全边界和人审控制。核心流程：
- 工单/告警接入：从监控系统或工单平台获取故障上下文
- 自动分诊：判断故障类型、影响范围、紧急程度
- 多源证据采集：拉取日志、指标、trace、配置、变更记录
- 根因假设：基于证据生成可能根因，按概率排序
- 处置建议：给出修复方案（重启/扩容/回滚/配置变更等）
- 人工审批：所有写操作必须人工确认
- 执行验证：审批通过后受控执行，验证修复效果
- RCA 复盘：沉淀根因分析报告，形成知识库

## 核心流程
```text
工单/告警接入 → 自动分诊 → 服务识别 → 多源证据采集
  → 根因假设 → 处置建议 → 人工审批 → 执行验证 → RCA 复盘
```

## 技术亮点
- **只读优先**：Agent 先收集证据、生成假设，不做变更
- **人审批**：重启、扩容、回滚、删除、配置变更等必须人工审批
- **模拟执行**：高风险操作先在 sandbox 模拟
- **受控执行**：审批通过后限制资源、超时、回滚
- **RCA 结构化**：根因链 + 证据链 + 影响范围 + 修复建议 + 预防措施
- **与 AI Coding Agent 架构互补**：一个是创造性任务，一个是诊断性任务

## 产品价值
- 缩短故障响应时间：自动分诊 + 证据采集替代人工排查
- 降低风险：人审批 + 模拟执行 + 受控执行 + 回滚
- 知识沉淀：RCA 报告 + 处置建议形成可复用知识库
