# 19.8 你的项目映射

> 所属分支：[[19-面试项目表达与案例沉淀层✅/_index|19-面试项目表达与案例沉淀层]]

## 子节点 / 待填充要点
- 三项目映射总览
- 25 个高频面试问题清单
- 面试题定位方法

## 一句话定义
将三核心项目（应用生成平台、AI Coding 工具包、运维智能体）映射到面试问答体系中，形成可快速检索的面试准备矩阵。

## 解决什么问题
面试中不同问题可能映射到不同项目，需要一个快速定位工具。

## 如何实现

### 三项目映射总览
| 项目 | 核心价值 | 核心技术栈 |
|------|----------|-----------|
| [[应用生成智能体项目✅]] | 企业级 AI 应用生成 | LlamaCoder + Together AI + MySQL + PG/Supabase + SSO + RLS + Sandpack |
| [[AI Coding工程化项目✅]] | AI Coding 工程化闭环 | Commands/Agents/Skills/Rules/Spec + Harness + Playwright + CI/CD |
| [[运维智能体项目-OpsPilot✅|运维智能体项目]] | AI 运维诊断与处置 | 分诊 + 证据采集 + 根因 + 人审批 + RCA |

### 25 个最高频面试问题清单
1. 你们为什么基于 LlamaCoder 改，而不是自研？
2. 原版 LlamaCoder 和你们改造后的平台有什么区别？
3. Together AI SDK 在系统里负责什么？
4. 你们的 runnable 是什么？和 LangChain Runnable 是一回事吗？
5. 前端怎么处理模型流式返回？
6. 为什么 Sandpack 在流式生成场景会卡？
7. 你们怎么优化长代码流式渲染？
8. Router、UIPlanner、SupabasePlanner、RoutingPlanner 分别负责什么？
9. Router 和 Planner 的区别是什么？
10. 为什么要拆多阶段生成，而不是一次性生成？
11. 平台数据为什么存 MySQL？
12. 用户业务数据为什么存 PostgreSQL / Supabase？
13. MySQL 和 Supabase 之间如何关联？
14. 企业 SSO 和 Supabase RLS 怎么打通？
15. tenant_id 从哪里来？如何保证可信？
16. RLS 的 `using` 和 `with check` 有什么区别？
17. 动态建表怎么保证安全？
18. 新旧 Schema 如何 diff 和迁移？
19. 如何避免 AI 每次全量重写项目？
20. AI Coding 里的 Command、Agent、Skill、Rule 是什么？
21. 什么是 Harness Engineering？
22. SDD / Spec Driven Development 怎么落地？
23. AI 生成代码后怎么验证？
24. Playwright 失败怎么判断是代码错还是用例错？
25. 怎么把 AI Coding 接入 CI/CD 并衡量 ROI？

- 听到"权限/多租户" → 映射到 31-企业权限身份多租户深水区

## 项目映射
- 三个项目覆盖 AI Coding + AI 应用生成 + AI 运维三大方向

## 高频追问
- 面试官可能追问"这些项目都是你主导的吗？"——回答：我负责核心架构设计和关键链路实现，包括 Router/Planner 设计、数据分层方案、权限体系、前端流式体验优化等。

## 我的回答要点
> 我的优势是把 AI 工具、前端工程、数据权限、测试验证和企业交付串成闭环。不是单点模型能力，而是工程化落地。
