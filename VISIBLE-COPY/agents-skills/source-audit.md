# source-audit

## Goal
Analyze a source code repository as evidence for AI / Agent interview preparation.

## Rules
- Read-only by default.
- Do not modify source code.
- Do not copy large source files into notes.
- Prefer file paths, function names, class names, and config names as evidence.
- Do not invent project metrics.
- Mark uncertain inferences as `待确认`.

## Checklist
1. Technology stack.
2. Package manager and scripts.
3. Entry points.
4. Directory structure.
5. Core modules.
6. Data flow / execution chain.
7. External integrations.
8. Tests and quality gates.
9. AI / Agent-related modules.
10. Interview evidence candidates.
11. Risks and missing implementation areas.
