# interview-question-generator

## Goal
Generate high-quality interview questions linked to existing Vault notes.

## Rules
- Generate questions only unless answers are explicitly requested.
- Link each question to an existing note where possible.
- Do not invent project metrics.
- Group questions by role or knowledge branch.

## Role groups
- 高级 Agent 开发
- 高级 AI 产品经理
- AI 平台产品经理
- AI 解决方案经理
- AI 架构师
- AI Coding / 研发效能负责人
