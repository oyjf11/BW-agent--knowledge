# source-deep-dive-questions

## Goal
Generate source-based interview follow-up questions.

## Rules
- Questions must be grounded in observed code structure or explicit missing implementation.
- Group by module or capability.
- Include why the question is dangerous or important.
- Do not generate answers unless explicitly asked.
