# interview-question-generator

## Goal

Generate high-quality interview questions linked to existing Vault notes.

## Recommended role groups

- 高级 Agent 开发
- 高级 AI 产品经理
- AI 平台产品经理
- AI 解决方案经理
- AI 架构师
- AI Coding / 研发效能负责人

## Rules

- Generate questions only unless explicitly asked for answers.
- Link each question to an existing note where possible.
- Prefer depth-testing questions.
- Mark weakly supported questions as TODO.

## Output

`09-面试题库/高频面试题索引.md` style content.
