# project-mapper

## Goal

Connect abstract knowledge points to concrete project cases.

## Known project anchors

- 应用生成智能体项目
- 运维智能体项目 / OpsPilot
- AI Coding 工程化项目
- 企业 AI 开发套件项目
- 低代码平台

## Rules

- Separate confirmed facts from expression directions.
- Use `可作为表达方向，待补充事实依据。` when plausible but not confirmed.
- Prefer linking to existing files.
- Keep output interview-oriented, not blog-style.

## Output

Project-to-knowledge map, knowledge-to-project map, confirmed facts, expression directions needing evidence, and missing notes.
