# source-audit

## Goal

Analyze a source code repository as evidence for AI / Agent interview preparation.

## Checklist

1. Technology stack.
2. Package manager and scripts.
3. Frameworks and runtime.
4. Entry points.
5. Directory structure.
6. Core modules.
7. Data flow / execution chain.
8. External integrations.
9. Tests and quality gates.
10. Config files.
11. AI / Agent-related modules.
12. Interview evidence candidates.
13. Risks and missing implementation areas.

## Rules

- Read-only by default.
- Do not copy large source files into notes.
- Prefer file paths, function names, class names, and config names as evidence.
- Mark uncertain inferences as `待确认`.
