# source-to-resume-bullets

## Goal

Create resume-safe bullet points grounded in source code and known project facts.

## Rules

- Do not invent metrics.
- Do not claim ownership unless supported by user-provided facts.
- Separate: 可直接写入简历 / 需要补证据后再写 / 不建议写.
- Prefer concrete mechanisms over vague claims.

## Output

Resume bullets, evidence paths, gaps, and risky claims to avoid.
